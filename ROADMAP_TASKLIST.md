## P0 - Harus Beres Sebelum Production Merge

- [x] Tambahkan authentication middleware untuk seluruh endpoint backend.
  - Owner: Backend Lead
  - Acceptance criteria: semua endpoint mutasi dan artifact access membutuhkan token valid; endpoint publik hanya `/health` atau readiness yang aman.
  - Progress 2026-05-19: backend middleware `authenticateRequest` sudah ditambahkan dan endpoint non-`/health` sudah protected. Frontend tidak lagi memakai `VITE_ANALYSIS_API_TOKEN`; API client memakai cookie credentials. `/auth/session` sudah dibatasi `AUTH_SESSION_EXCHANGE_ENABLED` + `AUTH_SESSION_EXCHANGE_KEY`, diberi rate limit, dan startup fail-fast sudah memvalidasi secret placeholder. Catatan residual: untuk production tetap perlu login/user identity flow yang benar, bukan static token exchange.

- [x] Terapkan authorization role-based.
  - Owner: Backend Lead + Product Owner
  - Acceptance criteria: role `viewer`, `operator`, `admin` minimal tersedia; hanya admin/operator yang dapat upload, delete, run analysis, ubah model config, atau update AI assist config.

- [x] Kunci CORS dengan origin allowlist.
  - Owner: Backend Lead / DevOps

  - Progress 2026-05-19: `CORS_ORIGINS` allowlist sudah ditambahkan dan default/example sudah mencakup Vite dev port `8080`.

- [x] Harden input path untuk video, model, ROI, zone, dan output artifact.
  - Owner: Backend Lead
  - Acceptance criteria: client tidak boleh mengirim arbitrary absolute path; API menerima `mediaSourceId`, `modelVersionId`, atau managed upload ID; backend resolve path dari registry dan realpath allowlist.
  - Progress 2026-05-19: validasi managed path untuk video/model/config sudah ditambahkan dan output artifact memakai signed URL ber-expiry.
  - Progress 2026-05-19 review lanjutan: jalur `no-helmet` sudah mulai resolve `mediaSourceId` dan `modelVersionId` server-side serta punya test regresi untuk managed ID dan legacy path.
  - Selesai 2026-05-19: kontrak normal frontend-to-backend untuk `no-helmet`, `no-safety-vest`, `no-life-vest`, `working-at-height`, `red-light-violation`, dan `dump-truck-bed-open` tidak lagi mengirim raw server path. Backend resolve video dari `mediaSourceId`, model dari `modelVersionId`/module config/model registry, dan ROI/zone/stop-line dari module config atau generated polygon. Legacy path fallback tetap ada hanya sebagai compatibility/debug path dan tetap dibatasi managed roots.
  - Review 2026-05-28: residual security ditemukan pada AI assist snapshot resolver: `snapshotUrl` masih dapat berupa absolute local path yang ada di filesystem dan dipakai untuk membuat image data URL.   - Review 2026-05-28 verifikasi lanjutan: residual AI assist snapshot sudah ditutup.
